# 觅色

> 通过 30 道空间审美选择题，找到属于你的色彩人格。

「觅色」是一款沉浸式色彩人格探索应用。它不是让你直接挑选喜欢的颜色，而是通过你在建筑空间、材质、光影与氛围上的直觉偏好，反向推演出你的色彩人格。

## 玩法

- **30 道直觉选择题**：凭直觉选择最吸引你的空间、材质、光线与氛围
- **色彩人格分析**：根据色相、饱和度、明度、冷暖与对比度，匹配 20 种色彩人格
- **结果揭示**：动画展示你的色彩人格，包含专属色板、材质关键词与空间氛围
- **色彩空间**：查看你的主导色相、饱和度、明度、冷暖倾向，以及匹配人格的完整描述

## 技术栈

- React 19 + TypeScript
- Vite 6
- Three.js / @react-three/fiber（入口 3D 空间场景）
- Tailwind CSS
- GSAP

## 快速开始

```bash
pnpm install
pnpm dev
```

生产构建：

```bash
pnpm build
pnpm preview
```

## 目录结构

```text
src/
├── components/     # 入口、测试、结果揭示、色彩空间
├── data/           # 30 道题目与 20 种人格数据
├── utils/          # 色彩分析算法
└── types/          # 类型定义
```

## 数据

- `questions.ts`：30 道关于空间、材质、光影与氛围的选择题
- `personalities.ts`：20 种色彩人格，含专属色板、材质、关键词与描述
- `algorithm.ts`：基于 HSB + 冷暖 + 对比度距离匹配最接近的人格
